# Retail Sales Analysis using Microsoft Excel

## Project Overview
This project focuses on analyzing retail sales data using Microsoft Excel to identify sales trends, understand business performance, and generate meaningful insights.

## Objectives
- Analyze overall retail sales performance.
- Identify sales trends and patterns.
- Understand product and category performance.
- Present insights through an interactive dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Data Visualization
- Excel Functions

## Project Files
- Raw Dataset
- Cleaned Dataset
- Excel Dashboard

## Key Learnings
- Data cleaning and preparation
- Exploratory data analysis
- Dashboard development
- Analytical and problem-solving skills

## Conclusion
This project demonstrates how Microsoft Excel can transform raw retail data into meaningful business insights for better decision-making.
